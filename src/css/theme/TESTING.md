## 📝 测试注意事项

1. **清除缓存**: 测试前建议清除浏览器缓存，确保加载最新的CSS文件
2. **控制台监控**: 始终保持浏览器控制台打开，观察日志输出
3. **多次测试**: 每个功能至少测试3次，确保稳定性

## 🔧 调试技巧

### 检查主题是否正确加载
```javascript
// 在浏览器控制台执行
console.log('当前主题:', document.body.getAttribute('data-theme'));
console.log('主题变量:', getComputedStyle(document.documentElement).getPropertyValue('--primary-color'));
```

### 手动切换主题
```javascript
// 在浏览器控制台执行
document.body.setAttribute('data-theme', 'dark'); // 或 'light', 'sakura'
```

### 检查CSS文件加载
```javascript
// 在浏览器控制台执行
Array.from(document.querySelectorAll('link[rel="stylesheet"]')).forEach(link => {
  console.log(link.href);
});
```

### 检查CSS变量
```javascript
// 在浏览器控制台执行
const styles = getComputedStyle(document.documentElement);
console.log('Primary Color:', styles.getPropertyValue('--primary-color'));
console.log('Background Primary:', styles.getPropertyValue('--bg-primary'));
console.log('Text Primary:', styles.getPropertyValue('--text-primary'));
```
