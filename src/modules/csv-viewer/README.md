# CSV浏览器模块

## 概述
这是一个现代化的CSV文件浏览器，采用模块化设计，支持大文件加载、实时搜索、排序和分页功能。

## 目录结构
```
src/modules/csv-viewer/
├── csv-viewer.js              # 主应用逻辑
├── components/                # 组件目录
│   ├── CSVTable.js           # 表格组件
│   ├── CSVPagination.js      # 分页组件
│   └── CSVSearch.js          # 搜索组件
├── utils/                    # 工具类目录
│   └── CSVUtils.js          # CSV处理工具
├── styles/                   # 样式目录
│   └── csv-viewer.css       # 主样式文件
└── README.md                # 文档文件
```

## 主要功能

### 🎯 核心功能
- **文件加载**: 支持从后端接收CSV数据
- **数据展示**: 响应式表格，支持横向和纵向滚动
- **实时搜索**: 支持关键词搜索，实时过滤数据
- **列排序**: 点击表头进行升序/降序排序
- **分页浏览**: 支持50/100/500行或全部显示
- **数据导出**: 导出当前过滤结果为CSV文件

### 🎨 界面特性
- **现代化设计**: 参考主界面设计风格
- **主题同步**: 自动跟随主应用主题（亮色/暗色/樱花）
- **响应式布局**: 适配不同屏幕尺寸
- **动画效果**: 流畅的加载和交互动画
- **无边框设计**: 与主界面风格保持一致

### ⌨️ 快捷键支持
- `Ctrl + F`: 聚焦搜索框
- `Ctrl + R`: 刷新数据
- `Ctrl + W`: 关闭窗口

## 技术架构

### 组件系统
采用模块化组件设计，每个组件职责单一：

#### CSVTable 表格组件
```javascript
// 使用示例
const table = new CSVTable(tableElement, {
    onCellClick: (row, column, value) => {
        console.log('单元格点击', { row, column, value });
    },
    onSort: (columnName, direction) => {
        console.log('排序', { columnName, direction });
    }
});
```

#### CSVPagination 分页组件
```javascript
// 使用示例
const pagination = new CSVPagination(containerElement, {
    onPageChange: (page) => console.log('切换到第', page, '页'),
    onRowsPerPageChange: (rows) => console.log('每页显示', rows, '行')
});
```

#### CSVSearch 搜索组件
```javascript
// 使用示例
const search = new CSVSearch(inputElement, {
    onSearch: (keyword) => console.log('搜索:', keyword),
    onClear: () => console.log('清除搜索')
});
```

### 工具类系统

#### CSVUtils 数据处理工具
提供CSV数据处理的静态方法：
- `searchRows()`: 搜索数据行
- `sortRows()`: 排序数据行
- `arrayToCSV()`: 数组转CSV格式
- `detectDataType()`: 自动检测数据类型

## 使用指南

### 基本使用
1. 在主应用中调用 `open_csv_viewer()` 函数
2. 传入CSV文件路径和窗口标题
3. 系统会自动创建新窗口并加载数据

### 数据格式
后端通过 `csv-data` 事件发送数据：
```json
{
    "filename": "test_data.csv",
    "headers": ["列1", "列2", "列3"],
    "rows": [
        {"列1": "值1", "列2": "值2", "列3": "值3"},
        {"列1": "值4", "列2": "值5", "列3": "值6"}
    ]
}
```

## 故障排除

### 常见问题

#### 1. 窗口无法创建
**症状**: 调用CSV浏览器时没有新窗口弹出
**原因**: 后端窗口配置问题
**解决**: 检查 `skip_taskbar` 设置，应设为 `false`

#### 2. 样式显示异常
**症状**: 界面样式与主应用不一致
**原因**: 主题同步失败
**解决**: 检查 `localStorage` 中的 `app-theme` 设置

#### 3. 数据加载失败
**症状**: 显示加载状态但无数据
**原因**: 事件监听失败或数据格式错误
**解决**: 检查控制台错误信息和数据格式

#### 4. 搜索功能异常
**症状**: 搜索无结果或程序卡死
**原因**: 数据量过大或搜索算法问题
**解决**: 启用分页搜索或优化搜索算法
