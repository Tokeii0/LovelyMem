# EXIF查看器模块

## 概述

EXIF查看器是Lovelymem V2中的一个专业工具模块，用于查看和分析图片文件的EXIF元数据信息。该模块提供了完整的EXIF数据读取、显示、搜索、过滤和导出功能。

## 功能特性

### 🖼️ 图片格式支持
- **JPEG/JPG**: 完整的EXIF数据支持
- **TIFF/TIF**: 专业相机格式支持
- **RAW格式**: CR2, NEF, ARW, DNG, ORF, RW2, PEF, SRW, RAF等
- **其他格式**: 3FR, FFF, DCR, KDC, SRF, MRW, X3F, ERF, MEF, MOS, CRW

### 📋 EXIF信息分类
- **基本信息**: 图像尺寸、分辨率、方向等
- **相机信息**: 制造商、型号、软件版本等
- **拍摄参数**: 曝光时间、光圈、ISO、焦距、闪光灯等
- **GPS位置**: 经纬度、海拔、时间戳等
- **时间信息**: 拍摄时间、修改时间、数字化时间等
- **技术参数**: 色彩空间、EXIF版本、组件配置等

### 🔍 搜索和过滤
- **实时搜索**: 支持标签名称和值的实时搜索
- **分类过滤**: 按EXIF数据分类进行过滤显示
- **多选过滤**: 支持同时选择多个分类
- **清除功能**: 一键清除搜索条件

### 📊 数据展示
- **表格视图**: 结构化的表格展示方式
- **分类展示**: 按分类组织显示EXIF数据
- **详情查看**: 点击查看单个标签的详细信息
- **值截断**: 长值自动截断，支持展开查看
- **排序功能**: 支持按标签名、值、分类排序

### 💾 导出功能
- **JSON格式**: 结构化数据导出，保留完整信息
- **CSV格式**: 表格格式导出，便于Excel处理
- **TXT格式**: 纯文本格式导出，便于阅读
- **剪贴板**: 支持复制单个值或全部数据到剪贴板

### 🎨 用户界面
- **现代化设计**: 遵循Lovelymem V2主界面设计语言
- **主题适配**: 完全适配浅色、深色、sakura三种主题
- **响应式布局**: 支持不同屏幕尺寸的自适应显示
- **拖拽支持**: 支持文件拖拽选择
- **进度指示**: 加载大文件时显示进度

## 使用方法

### 启动EXIF查看器
1. 在Lovelymem V2主界面中，进入"小工具"区域
2. 点击"EXIF查看器"工具卡片
3. 系统将打开独立的EXIF查看器窗口

### 选择图片文件
1. **拖拽方式**: 直接将图片文件拖拽到文件选择区域
2. **浏览方式**: 点击"浏览文件"按钮选择图片文件
3. **支持格式**: 系统会自动验证文件格式是否支持

### 查看EXIF信息
1. 文件加载完成后，EXIF信息将自动显示在表格中
2. 信息按分类组织，每个分类可以展开/收起
3. 点击"🔍"按钮可查看单个标签的详细信息
4. 点击"📋"按钮可复制单个标签的值

### 搜索和过滤
1. 在搜索框中输入关键词进行实时搜索
2. 使用分类复选框选择要显示的EXIF分类
3. 点击"清除"按钮重置搜索条件

### 导出数据
1. 点击"导出数据"按钮
2. 选择导出格式（JSON、CSV、TXT）
3. 选择保存位置
4. 确认导出

## 集成说明

### 主应用集成
EXIF查看器已完全集成到Lovelymem V2主应用中：

1. **功能注册**: 在`toolsArea.ts`中注册为小工具功能

3. **事件处理**: 在`EventManager`中处理功能触发事件

## 开发和扩展

### 添加新的EXIF标签支持
1. 在`EXIFUtils.js`的`tagDisplayNames`中添加标签映射
2. 在`tagCategories`中添加分类信息
3. 在格式化方法中添加特殊处理逻辑

### 添加新的导出格式
1. 在`EXIFExporter.js`中添加新的导出方法
2. 更新格式选择对话框
3. 添加相应的文件扩展名支持

### 自定义主题
1. 在`exif-viewer.css`中添加新的主题变量
2. 定义主题特定的颜色和样式
3. 确保与主应用主题保持一致

## 注意事项

1. **文件大小限制**: 建议处理的图片文件不超过100MB
2. **格式兼容性**: 某些RAW格式可能需要特定的解码库支持
3. **隐私保护**: GPS信息等敏感数据需要用户确认后才能导出
4. **性能优化**: 大量EXIF标签时会自动启用虚拟滚动
5. **错误处理**: 损坏的图片文件会显示友好的错误提示
