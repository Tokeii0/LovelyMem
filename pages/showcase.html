WHAT V2 CHANGES

从“能运行命令”，
到“能完成调查”。

01 / WORKSPACE

证据留在上下文里

命令输出不再只是散落的 CSV。进程、网络、文件、注册表、EVTX 与时间线拥有面向调查的专用视图，并能继续进入搜索、关联和报告流程。

02 / TOOLCHAIN

工具链成为产品能力

Python、MemProcFS、Volatility 与 MemNixFS 可从官方来源安装，完成校验、探针、配置回填与失败回滚。

03 / SAFETY

默认拒绝不可信安装

官方域名、HTTPS、SHA-256、安全解压与暂存切换构成下载边界；系统驱动仍保留人工安装与确认。

04 / NATIVE CORE

系统能力回到 Rust

进程、文件、数据库、图像与大文件处理由 Rust 后端承载，前端专注工作流呈现和交互。

05 / AGENT

AI 从回答走向执行

可选 Agent 能在授权范围内浏览文件、检索内容、分析 CSV 与注册表，并调用取证工具；提供商和数据边界由用户配置。

06 / LANGUAGE

跨窗口运行时双语

简体中文与 English 不再只停留在局部设置。V2 的翻译运行时覆盖主界面和主要独立查看器，并在语言变更后同步窗口状态。
